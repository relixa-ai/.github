# Relixa

Entity matching at massive scale.

Relixa builds high-performance entity matching engines for enterprises. Find record pairs across different systems that refer to the same customer, company, product or supplier.

## What we build

Entity matching has two stages. Blocking narrows the possible record pairs to a set of candidates. Matching identifies which candidates refer to the same entity.

- **Sparkly**: Fast blocking that selects candidate pairs without requiring you to design blocking rules.
- **Delex**: Flexible, rule-driven blocking for greater control over candidate selection.
- **Iris**: Learns from labeled examples to identify matching records, with active learning to help collect labels.

Our product editions support workflows ranging from a single machine to enterprise deployments on premises or in your cloud.
